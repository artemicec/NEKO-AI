# Скриншоты для README

Эта папка нужна README: он ссылается на шесть картинок. Положи сюда свои (имена должны совпадать):

| Файл | Что снять |
| --- | --- |
| `neko.png` | NEKO на рабочем столе: аватар в окне, лучше поверх красивых обоев |
| `aria.png` | ARIA: окно с «объективом» и панелью состояния |
| `chat.png` | диалог (пара реплик, одна — с командой вроде «напомни…» или «погода»), без личного |
| `settings.png` | окно настроек, например «Голос и звук» или «Проверка и установка» |
| `diary.png` | дневник NEKO со списком записей и статистикой эмоций |
| `diary-pdf.png` | экспортированный PDF дневника (первая страница) |

**Перед тем как коммитить скриншоты, проверь, что на них нет:** API-ключей (страница «Нейросеть и система»!), личной переписки, настоящих имён, адресов, путей вида `C:\Users\<твоё имя>\…`, вкладок браузера и уведомлений.
Лучше сделать снимки на «чистой» тестовой переписке. PNG до 1–2 МБ; в README картинки вставлены таблицей по две в ряд.

Пока файлов нет, картинки в README на GitHub показываются как «битые» — это нормально до первого коммита скриншотов.
`npm run check:publish` предупредит, если скриншотов меньше четырёх.
