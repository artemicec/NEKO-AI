# NEKO / ARIA — 0.1, часть 1 (API нейросетей, озвучка ElevenLabs/Cartesia, паузы анимаций)

Распакуй поверх проекта (`F:\NEKO_AI`) с заменой файлов, затем **удали старый файл** `src/shared/services/deepseekService.ts`
(его заменил `openaiCompatService.ts`). `npm install` не нужен — зависимостей не добавлено.
Остальное из списка 0.1 (README/SETUP/LICENSE и др., мастер настройки, экспорт дневника, напоминания, трей) придёт следующим пакетом.

## 1. Больше API нейросетей
Настройки → «Система» → «Нейросеть»: Ollama (локально) и в облаке — DeepSeek, OpenAI, Anthropic (Claude), Google Gemini, OpenRouter,
Groq, Mistral, Together AI, xAI (Grok) и «Свой сервер» (любой OpenAI-совместимый: LM Studio, vLLM, llama.cpp…).
У каждого — свой ключ, адрес и модель; кнопка «Список моделей» подтягивает актуальные названия прямо у провайдера, ссылка «Получить ключ».
- Старый ключ DeepSeek переносится автоматически (поля `deepseek*` → `cloud.deepseek`).
- OpenAI: учтены новые параметры (`max_completion_tokens`, модели без `temperature`) — при отказе сервера запрос один раз повторяется без спорного параметра.
- Anthropic идёт собственным клиентом (Messages API, стрим). Gemini — через его OpenAI-совместимый слой.
- Ошибки по-русски с учётом провайдера (неверный ключ, нет баланса, лимит, нет модели); ключ в текстах ошибок не появляется.
- `electron/cors.ts`: CORS-заплатка теперь знает облачные хосты; адрес «своего сервера» разрешается автоматически (канал `net:allow-host`).

## 2. Озвучка ElevenLabs и Cartesia
Настройки → «Голос» → «Движок». Ключ, модель, язык, **ID голоса отдельно для NEKO и ARIA**, кнопка «Загрузить голоса», «Проверить голос»
(показывает точную причину, если облако не ответило). Звук идёт тем же путём, что Chatterbox: предзагрузка следующих предложений,
липсинк по настоящему звуку, отмена при «стоп»; при ошибке — откат на системный голос (после ошибки ключа/лимита облако не дёргается 5 минут).
Облако платное, текст ответов уходит на серверы провайдера (в настройках об этом предупреждение).

## 3. Анимации реже
Раньше следующий клип запускался по таймеру от СТАРТА предыдущего — клипы шли встык. Теперь: **стандартная поза (первый клип `idle…`) → один клип →
плавный возврат в позу → пауза → следующий клип** (никогда один и тот же дважды подряд). Пауза — «Пауза между анимациями» (5–300 с, по умолчанию 30,
со случайным разбросом ±40%). Анимации не стартуют, пока аватар говорит или окно скрыто. Работает у NEKO и ARIA.
Настройка `animationInterval` заменена на `animationPause`.

## Проверка
Тесты (новые: `providers`, `tts_cloud`, `animation_scheduler`) и все прежние проходят; типы SFC и Electron чистые.
**Не проверено вживую** (в среде разработки нет сети/Electron/звука): реальные ответы OpenAI/Anthropic/Gemini/ElevenLabs/Cartesia —
форматы запросов сверены с документацией ElevenLabs и Cartesia, остальные написаны по знанию API и проверены против локального сервера-заглушки;
вид аватара при возврате в позу. Имена моделей по умолчанию (`providers.ts`) могут устареть — выбирай из «Списка моделей».
