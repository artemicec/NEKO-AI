# Установка и первый запуск

[English](SETUP.en.md)

Проект проверялся на **Windows 10/11**. На macOS и Linux запуск из исходников, скорее всего, тоже работает, но это не проверялось.

Обязательно нужны только две вещи: **Node.js** и **какая-нибудь нейросеть** (локальная Ollama или ключ облачного провайдера). Всё остальное — голос, картинки, аватар — добавляется по желанию, в любом порядке.

## 1. Запуск программы

Нужен [Node.js](https://nodejs.org) версии 18 или новее (подойдёт LTS).

```bash
git clone <адрес этого репозитория>
cd <папка проекта>
```

**Windows, самый простой способ:** двойной клик по `NEKO.bat` (аватар-вайфу) или `ARIA.bat` (ассистент в стиле Джарвиса).
В первый раз файл сам установит зависимости и соберёт приложение (несколько минут, нужен интернет), потом запускается за секунды.
После обновления кода пересобирает автоматически.

Чтобы запускать без папки проекта, создай ярлыки на рабочем столе:

```bash
npm run shortcuts
```

Другие способы:

| Команда | Что делает |
| --- | --- |
| `npm run start:neko` / `npm run start:aria` | то же, что `.bat`, но из терминала (работает и на macOS/Linux) |
| `npm run dev:neko` / `npm run dev:aria` | режим разработки: сервер Vite + горячая перезагрузка |
| `npm run build:neko` / `npm run build:aria` | установщик Windows в папке `release/` |

> **Про настройки.** Собранная версия (`NEKO.bat`, установщик) и режим разработки (`npm run dev:*`) хранят настройки окон отдельно: у них разный адрес страниц.
> Если раньше запускал `dev:*` и потом перешёл на `NEKO.bat`, настройки и ключи придётся ввести заново. История чата и дневник лежат в папке данных и **сохраняются**.

> **Про установщик.** Файлы моделей `.vrm` в репозиторий не входят (у моделей свои лицензии), поэтому установщик, собранный командой `build:*`,
> не содержит аватара. Пока что самый простой путь — запуск из исходников: положи свою модель в `public/models/` (см. шаг 3).

## 2. Нейросеть (обязательно)

Выбери один из вариантов в «Настройки → Нейросеть и система».

### Вариант А: Ollama (локально, бесплатно, данные не уходят в интернет)

1. Установи Ollama: <https://ollama.com/download> и запусти (значок в трее).
2. Скачай модель. В настройках по умолчанию стоит `gemma4:e4b`:
   ```bash
   ollama pull gemma4:e4b
   ```
   Если такой модели в каталоге Ollama нет (названия моделей меняются), выбери любую другую: «Нейросеть и система» → кнопка «Список моделей» покажет то, что уже скачано.
3. Адрес по умолчанию — `http://localhost:11434`.

Хватит ли видеокарты — зависит от модели; на слабом компьютере бери модель поменьше.

### Вариант Б: облачный провайдер (нужен ключ и деньги/квота у провайдера)

Поддерживаются DeepSeek, OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, Mistral, Together, xAI и «свой сервер» (любой OpenAI-совместимый, например LM Studio или vLLM).
Выбери провайдера, вставь ключ (ссылка «Где взять ключ» — под полем), нажми «Список моделей» и выбери модель.

> ⚠️ Ключ хранится на твоём компьютере **без шифрования**. Никому не показывай папку данных приложения и не делай скриншоты настроек с ключом.
> Подробности — в [PRIVACY.md](PRIVACY.md).

## 3. Аватар (VRM-модель)

Аватар — файл формата **VRM** (VRM 0.x или 1.0).

| Для кого | Куда положить |
| --- | --- |
| NEKO | `public/models/default.vrm` |
| ARIA (необязательно; без файла вместо модели показывается «объектив») | `public/models/aria.vrm` |

Где взять модель: [VRoid Hub](https://hub.vroid.com), [Booth](https://booth.pm), или нарисуй свою в VRoid Studio.
**Проверь лицензию модели**: многие запрещают перераспространение — поэтому файлы `.vrm` в `.gitignore` и в репозиторий не попадают.

Скачать образец для проверки:

```bash
npm run models:download
```

Скрипт берёт адрес из `scripts/models.json`. Этот адрес автор проекта **не проверял вживую**, поэтому он помечен `"verified": false`: если не скачалось, возьми модель вручную.
Скрипт проверяет, что скачан именно VRM (а не страница с ошибкой). Своя ссылка: `npm run models:download -- --url https://… --target public/models/aria.vrm`.

**Анимации** (необязательно): без них аватар просто стоит в базовой позе. Файлы `VRMA_01.vrma … VRMA_07.vrma` кладутся в `public/animations/` — подробности в [public/animations/README.md](public/animations/README.md).

## 4. Голосовой ввод: Whisper (необязательно)

Без него можно писать сообщения. С ним — говорить в микрофон. Whisper работает локально.

1. Нужен OpenAI-совместимый сервер распознавания речи. Проверялось с проектом [speaches](https://github.com/speaches-ai/speaches) (бывший faster-whisper-server): у него есть образ Docker и инструкция по запуску.
   Команды у таких проектов меняются, поэтому берись за актуальный README проекта, а не за пример здесь.
2. В приложении («Голос и звук» → «Распознавание речи») выбери «Whisper». По умолчанию: адрес `http://localhost:8000/v1`, модель `Systran/faster-whisper-small`.
3. Разреши доступ к микрофону, когда попросит система.

## 5. Озвучка (необязательно)

«Настройки → Голос и звук → Озвучка». У NEKO и ARIA свои голоса.

| Движок | Что нужно | Качество |
| --- | --- | --- |
| Встроенный | ничего | простой голос системы |
| Chatterbox | локальный сервер, по умолчанию `http://localhost:4123` | естественный, можно клонировать голос; нужна видеокарта |
| ElevenLabs | ключ [elevenlabs.io](https://elevenlabs.io/app/settings/api-keys) | облако, много голосов |
| Cartesia | ключ [play.cartesia.ai](https://play.cartesia.ai/keys) | облако, быстрый |

Для Chatterbox приложение отправляет запросы на `<адрес>/audio/speech` (формат, как у OpenAI). Подходит сервер, который так умеет, — например проект
[chatterbox-tts-api](https://github.com/travisvn/chatterbox-tts-api) на основе [Chatterbox](https://github.com/resemble-ai/chatterbox). Установка по его README.
Для облачных движков есть кнопка «Проверить голос» и «Загрузить голоса».

> Текст ответов уходит облачному движку озвучки (ElevenLabs/Cartesia). Если это неприемлемо — используй встроенный голос или Chatterbox.

## 6. Картинки: Stable Diffusion (необязательно)

Нужны для команды «нарисуй …» и для селфи/иллюстраций в дневнике NEKO.

1. Установи [AUTOMATIC1111 WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui).
2. Запускай его с флагом `--api` (в `webui-user.bat`: `set COMMANDLINE_ARGS=--api`).
3. Адрес по умолчанию — `http://127.0.0.1:7860` («Настройки → Картинки»).

## 7. Мастер «Проверка и установка»

При самом первом запуске само откроется окно настроек на странице **«Проверка и установка»**. Оно за пару секунд проверяет нейросеть, модель аватара, анимации,
Whisper, Chatterbox и Stable Diffusion; рядом с каждым пунктом — ✅/⚠️/➖/⛔, подсказка и ссылка на установку. Открыть снова: «Настройки → Проверка и установка».

## 8. Полезное

- **Трей.** Значок в трее: «Открыть NEKO/ARIA», «Чат», «Дневник», «Настройки», «Выход». Пока включено «Закрытие прячет в трей» (по умолчанию), крестик на окне **не завершает** приложение — оно продолжает работать: сработают напоминания, запишется дневник. Совсем закрыть — значок → «Выход». Отключается в «Интерфейс».
- **Напоминания.** Напиши: «напомни через 10 минут выпить воды», «напомни завтра в 9 утра про встречу», «покажи напоминания», «отмени все напоминания». Сработавшее напоминание появляется окошком в правом нижнем углу экрана.
- **Дневник.** Кнопка «⬇️ Экспорт» сохраняет записи в Markdown (картинки — в папку рядом) или в PDF. В строке поиска можно писать словами: «когда мне было грустно» — найдутся записи про грусть; то же спрашивает и сама NEKO в чате.
- **Автозапуск с Windows:** «Настройки → Интерфейс».

## 9. Если что-то не работает

| Что видишь | Что делать |
| --- | --- |
| `Missing script: "…"` при `npm run …` | устаревший `package.json`; обнови проект до последней версии |
| `Electron failed to install correctly` | удали папку `node_modules` и выполни `npm install` ещё раз |
| Аватара нет, есть только кнопки | нет файла модели — страница «Проверка и установка» покажет, какой |
| «Ollama не отвечает» | запущена ли Ollama (значок в трее); `ollama list` в терминале должен отвечать |
| Модель не отвечает / 400 / 404 у облака | неверное имя модели — нажми «Список моделей» и выбери из списка; проверь ключ |
| Whisper «не слышит» | сервер запущен? разрешён ли микрофон? совпадают ли адрес и модель в настройках |
| Озвучка молчит | «Проверить голос» в «Голос и звук» покажет причину; облачные движки после ошибки временно отключаются на 1–5 минут |
| Порт 5173 занят (только `dev:*`) | закрой другой запущенный Vite |
| SmartScreen ругается на установщик | установщик не подписан сертификатом; запусти через «Подробнее → Выполнить в любом случае» или собери из исходников |
| Окно «пропало» | значок в трее → «Открыть NEKO» |

Не помогло — открой issue и приложи текст ошибки (**без ключей и личных данных**).
